
# Next.js Project Setup Package

⚡ A boilerplate and starter kit for Next.js 15 with App Router and Page Router support, Tailwind CSS 3.4, and TypeScript. This package is designed to enhance developer experience by providing essential tools for modern web development.

## Features

- **Next.js 15**: Utilize the latest features of Next.js with both App Router and Page Router support.
- **TypeScript**: Improve code quality and maintainability with TypeScript.
- **Tailwind CSS**: Build custom designs rapidly using utility-first CSS.
- **Testing Tools**: Choose from Vitest, Jest, or Mocha + Chai for unit testing and Playwright, Selenium, or Cypress for end-to-end testing.
- **Import Aliasing**: Set up import aliasing for cleaner imports.
- **Folder Structure**: Select from simple, medium, or advanced folder structures.
- **Coding Style**: Configure ESLint according to your preferred coding style (development/production/accessibility).
- **Monitoring**: Install Sentry for error tracking.
- **Deployment Options**: Deploy your application on platforms like Netlify, Vercel, or Heroku.
- **Code Coverage**: Integrate Codecov for code coverage reporting.
- **Code Quality Tool**: Use SonarQube for comprehensive code quality analysis.
- **Docker Support**: Containerize your application with Docker.
- **Storybook Setup**: Develop UI components in isolation with Storybook.
- **Git Hooks**: Manage Git hooks using Husky and lint staged files with Lint-Staged.
- **Commitlint**: Enforce commit message conventions to maintain a clean commit history.
- **Semantic Release**: Automatically manage versioning and package publishing based on commit messages.

## Getting Started

### Prerequisites

Ensure you have the following installed:

- [Node.js](https://nodejs.org/) (version 14 or later)
- [npm](https://www.npmjs.com/) (comes with Node.js)

### Installation

To create a new Next.js project using this setup package, run the following command in your terminal:

```
npx create-next-app@latest my-nextjs-app
```

Follow the prompts to configure your project according to your preferences.

### Configuration Options

During the installation process, you will be prompted to customize various aspects of your project:

1. **Unit Testing Tools**: Select from Vitest, Jest, or Mocha + Chai for unit testing.
2. **End-to-End Testing Tools**: Choose between Playwright, Selenium, or Cypress for end-to-end testing.
3. **Import Alias**: Set up import aliasing for cleaner imports (e.g., `@components`, `@utils`).
4. **Source Folder Structure**: Decide whether to include a `src` folder for better organization.
5. **Folder Structure Complexity**: Choose between simple, medium, or advanced folder structures.
6. **Coding Style Configuration**: Configure ESLint based on your preferred coding style (development/production/accessibility).
7. **Monitoring Setup**: Install Sentry for error tracking and monitoring.
8. **Deployment Options**: Select a deployment platform (Netlify, Vercel, Heroku).
9. **Code Coverage Tool**: Install Codecov for tracking code coverage metrics.
10. **Code Quality Tool**: Use SonarQube for maintaining high code quality standards.
11. **Docker Support**: Set up Docker for containerization of your application.
12. **Storybook Setup**: Enable Storybook for developing UI components in isolation.
13. **Git Hooks Management**: Set up Husky for managing Git hooks and Lint-Staged for linting staged files.
14. **Commitlint Configuration**: Enforce commit message conventions with Commitlint.
15. **Semantic Release Setup**: Automatically manage versioning and publishing based on commit messages.

## Usage

After installation and configuration:

1. Navigate to your project directory:
   ```
   cd my-nextjs-app
   ```

2. Start the development server:
   ```
   npm run dev
   ```

3. Open your browser and visit `http://localhost:3000` to see your application in action!
